📋 Template Suivi Immobilier Locatif

Cliquez sur le bouton ci-dessous pour télécharger votre fichier Excel pré-rempli avec les colonnes à compléter.

Le fichier contient 4 onglets :
  • 🏠 Biens — liste de vos propriétés
  • 👤 Locataires — informations sur les locataires et les baux
  • 🏢 Syndic — frais de syndic par bien
  • 💶 Encaissements — suivi mensuel des loyers perçus

Remplissez chaque onglet, puis transmettez-le pour que le Dashboard soit configuré avec vos données.
